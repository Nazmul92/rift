# Pinned test / lint / type-check toolchain for the rift_v2 reference snapshot.

# identically in a clean environment. Resolved and verified on
# python:3.12-slim (Python 3.12.14, linux/amd64), the M0 reference environment.
#
#     python -m pip install -r requirements-dev.txt
#     PYTHONPATH=src python -m pytest tests -q
#     python -m ruff check src tests
#     python -m ruff format --check src tests
#     python -m mypy src
#
# Hashes are deliberately omitted: ruff and mypy publish per-platform wheels,
# so a hash-locked file would pin this snapshot to linux/amd64 and fail for a
# reviewer on another architecture. Versions are exact; artifacts are not.
